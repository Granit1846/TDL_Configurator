# Configurator: pages and what they do
<!-- visibility: normal -->

Configurator edits `Data\SKSE\Plugins\TDL_StreamPlugin.ini` and sends actions via `tdl_send.exe`.

## QuickAccess
- PING / open folders / create an INI template.
- Does not change INI (except creating the template).

## Chaos / Inventory / Wrath / Hunter / Gigant (Characteristics) / Comedy
- These tabs write INI sections:
  - Chaos → `[Chaos]`
  - Inventory → `[Inventory]`
  - Wrath → `[Wrath]`
  - Hunter → `[Hunter]`
  - Gigant/Characteristics → `[Gigant]`
  - Comedy → `[Comedy]` (if enabled)

Full keys: **06_INI_Settings.md**.

## Documentation
- Browse and search Markdown docs; open a doc in an external editor.

## Settings
- Game path (Skyrim root).
- **Advanced mode** (when enabled) shows the **Test** tab and the full documentation set. It takes effect only after **Save**.
