# Интеграция со стримом: как запускать стадии ботом/софтом
<!-- visibility: normal -->

TDL не привязан к конкретной платформе. Вам нужен любой инструмент, который умеет **запускать программу с аргументами** (exe/скрипт): стрим-бот, панель, макросы, донат-сервис, кастомный бот.

## Базовая команда (NORMAL)
Шаблон:
```txt
tdl_send.exe NORMAL <ACTION> [SOURCE]
```

Пример:
```txt
tdl_send.exe NORMAL COMEDY_ARENA 2
```

- `ACTION` — событие (см. **05_Stages_Actions.md**).
- `SOURCE` — приоритет источника (рекомендуется `2`, если не уверены).

Рекомендация по SOURCE (если используете несколько каналов одновременно):
- `1` — высокий приоритет (например донаты/bits)
- `2` — стандарт (channel points)
- `3` — низкий (голосования)

## Где брать tdl_send.exe
Типовой путь:
- `Data\TDL\Tools\tdl_send.exe`

Практика для ботов:
- либо задайте **Working Directory** = папка `...\Data\TDL\Tools\`,
- либо вызывайте exe по **полному пути** (важно при путях с пробелами — используйте кавычки).

Пример (полный путь):
```txt
"F:\SteamLibrary\steamapps\common\Skyrim Special Edition\Data\TDL\Tools\tdl_send.exe" NORMAL SYSTEM_PING 2
```

## Мини-набор привязок (пример)
- Channel Points “Heal” → `SYSTEM_HEALING` (SOURCE 2)
- Донат “Arena” → `COMEDY_ARENA` (SOURCE 1)
- Голосование “Teleport” → `TELEPORT_RANDOM_CITY` (SOURCE 3)

## Правила безопасности (практично)
1) **По умолчанию используйте NORMAL.**
2) FORCE/серии (BURST) давайте только модераторам или редким ивентам.
3) Ставьте кулдауны в боте (например 60–180 сек на тяжёлые события).
4) Телепорты не запускайте в диалоге/катсценах.
5) “Разрушительные” эффекты (например `INVENTORY_DROP_ALL`) делайте редкими и дорогими.

## Если команда не запускается
1) Проверьте `SYSTEM_PING`.
2) Проверьте, что игра загружена в сейв.
3) Смотрите **08_Logs_Diagnostics.md**.
